# VSM — меню для VPS

[![Проверки](https://github.com/adkudryashov/VSM/actions/workflows/checks.yml/badge.svg)](https://github.com/adkudryashov/VSM/actions/workflows/checks.yml)
[![Лицензия MIT](https://img.shields.io/badge/лицензия-MIT-blue)](LICENSE)

VSM ставит и обслуживает личный прокси-сервер на VPS: панель 3x-ui, прокси
для Telegram (telemt) и Telegram-бота, который присматривает за сервером.
Всё делается пунктами меню, без ручных команд.

## Что умеет

- **Ставит всё сразу.** Панель 3x-ui с сертификатами, прокси для Telegram,
  веб-панель к нему. Логины и пароли запоминает и показывает в одном месте.
- **Присматривает за сервером через бота.** Сообщает, если что-то упало,
  раз в сутки присылает сводку, показывает все ваши серверы одним экраном.
- **Не даёт обновлениям сбить настройки.** Чужие программы при обновлении
  возвращают свои умолчания. VSM это замечает и возвращает ваши.
- **Защищает сервер.** Бан за подбор пароля SSH, обновления безопасности раз
  в месяц, фаервол.
- **Помогает с переездом.** Суточная копия настроек, перенос шаблона панели
  на новый сервер, подписка для роутера с XKeen.
- **Проверяет сеть.** Доступность из России, скорость, качество IP.

## Установка

Нужны:
- чистый сервер на Ubuntu 24.04/26.04 или Debian 12/13;
- доступ root;
- два поддомена, направленные на адрес сервера. Какой для чего, установщик
  спросит сам.

```bash
bash <(curl -sL https://raw.githubusercontent.com/adkudryashov/VSM/main/install.sh)
```

После установки меню открывается командой `vsm`.

### Первый запуск

Делайте по порядку: каждый шаг опирается на предыдущий.

1. **Панель и прокси:** `vsm` → **2** → **1**. Меню спросит домены и порты.
   Логин и пароль панели установщик показывает один раз, VSM их запомнит.
2. **MTProxyL:** там же, пункт **9**. На первом вопросе выберите режим
   **Reanimator**.
3. **Бот:** `vsm` → **3** → **1**. Понадобятся токен от
   [@BotFather](https://t.me/BotFather) и ваш Telegram ID.
4. **Защита:** `vsm` → **5** → **8** (бан подбора SSH) и **9** (обновления).
5. **Проверка:** `vsm` → **2** → **4 «Диагностика»**.

Все адреса, логины и пароли собраны в пункте **0** главного меню. На главном
экране их нет намеренно: меню открывается при каждом входе на сервер.

## Обновление

| Что | Где |
|---|---|
| VSM | главное меню → **7** |
| telemt | **2** → **12**. Новая версия сначала пробуется рядом с рабочей, при сбое — откат |
| 3x-ui | **1** → **6** → Update. Сначала бэкап: **1** → **4** |

После «Применить патч» в разделе 3x-ui верните настройки: **2** → **5** и
**2** → **11**. Бот напомнит об этом сам.

## Бот

Ставится пунктом **3**. Кнопки в чате: состояние прокси и панелей, активные
подключения, карта, сторож с тревогами.

- **Сводка за сутки** приходит в 22:00 по Москве: трафик по клиентам,
  попытки взлома, сбои за день, что нужно обслужить. Кнопка под сводкой
  выключает рассылку. Кнопка **«📅 За сутки»** показывает сводку в любой
  момент.
- **Все серверы на одном экране**, если у вас стоит
  [beszel](https://beszel.dev). Агент и сам хаб ставятся пунктом **6** → **9**.
- **Присмотр за самим ботом.** Если бот замолчит, сообщение всё равно придёт:
  его шлёт отдельный таймер.

## Защита сервера

Раздел **5**, «Защита»:

- **Бан подбора SSH.** 3 неудачных входа за час — бан на 15 минут. Каждый
  следующий бан того же адреса длиннее: час, сутки, неделя, месяц, год.
  Бан действует и на вас. Забанили себя — войдите через консоль в кабинете
  хостера и снимите бан там же, пунктом «Разбанить адрес».
- **Автообновления.** Обновления безопасности раз в 30 дней, без
  перезагрузки. Новое ядро заработает после перезагрузки вручную.

## Копия и переезд

Раз в сутки VSM сохраняет свои настройки и снимок панели 3x-ui в
`/var/backups/vsm/config`. **Копия лежит на том же сервере**: пропадёт
сервер — пропадёт и она. Забирайте архив к себе.

Вернуть всё на новый сервер с теми же доменами:
1. поставить VSM и положить архив в `/root/`;
2. `bash /root/VSM/tools/vsm-backup.sh --restore /root/config-….tar.gz`;
3. `vsm` → **2** → **1**: установщик найдёт копию и предложит вернуть панель.

Ссылки клиентов продолжат работать. Перенести только оформление панели
(подписки, названия, параметры) на сервер с другими доменами: **1** → **9**.
