## 2. Главное архитектурное изменение

**telemt_panel уехала с открытого порта на 443 домена панели по случайному
32-символьному префиксу пути.**

Было: панель слушала `0.0.0.0:9444` и терминировала TLS своим сертификатом.
Снаружи это выглядело как админ-форма с валидным сертификатом на нестандартном
порту — сканеру хватало одного соединения, чтобы классифицировать сервер, и вся
работа по маскировке порта telemt теряла смысл.

Стало: панель слушает `127.0.0.1`, TLS терминирует nginx, наружу открыты только
443 и порт telemt. Побочно исчезла необходимость выдавать панели ACL на
приватный ключ Let's Encrypt — процесс, смотрящий в интернет, ключ больше не читает.

Три следствия, которые надо помнить:

1. **Блок доступа живёт в `sites-enabled`** и не переживает патч 3x-ui-pro — тот
   вычищает каталог целиком. Маска в `conf.d` переживает. Поэтому пункт 4
   переприменяет оба и называется «Восстановить конфиги nginx».
2. **Панель не умеет работать из подкаталога**: в её HTML зашиты `<base href="/">`
   и `window.__BASE_PATH__=""`. Лечится `sub_filter` — поддержка префикса в
   приложении есть, ему надо лишь сообщить непустое значение. Обязателен
   `proxy_set_header Accept-Encoding ""`, иначе sub_filter не правит сжатый ответ.
3. **Миграция старых установок** делается тем же пунктом 4: если `PANEL_PREFIX`
   в конфиге нет, он создаётся и дописывается.

## 3. Пересборка nginx — починена, на живом сервере не прогонялась

### Что было

```
./configure: error: the HTTP XSLT module requires the libxml2/libxslt
libraries. You can either do not enable the module or install the libraries.
```

Скрипт берёт `configure`-флаги из `nginx -V` и переводит динамические модули в
статические, **но не ставил их зависимости сборки**. Это причина, по которой
пересборка не проходила у владельца ни разу. Провал был безопасным:
`set -euo pipefail` обрывал работу до подмены бинарника.

### Что сделано

**Отбор модулей по факту, а не по списку.** Пять необязательных модулей
(`http_xslt`, `http_image_filter`, `http_perl`, `http_geoip`, `mail`)
вырезаются из `BUILD_ARGS`, если их директив нет в **эффективном** конфиге
(`nginx -T`, а не один файл). Если директива есть — модуль остаётся, а его
dev-пакет доставляется. Направление ошибки выбрано намеренно: греп идёт по
всему выводу, включая комментарии, и без правой границы слова, так что
`upstream image_filter_backend` засчитается за использование. Лишний пакет
дешевле упавшего `nginx -t` после подмены бинарника.

Список из прежней редакции этого документа был неполон: `http_geoip` тоже
требует `libgeoip-dev`, а `--with-mail` нельзя снимать без парного
`--with-mail_ssl_module`.

**`stream` защищён явно.** Перед `./configure` проверяется наличие
`--with-stream`, `--with-stream_ssl_module`, `--with-stream_ssl_preread_module`;
их отсутствие — `die` до единого изменения в системе. На них держится
SNI-роутинг 443 на панель и REALITY.

**OpenSSL теперь устанавливается.** Этап 1 делал `make`, но не `make install`,
поэтому `/opt/openssl-3.5` не появлялся никогда. Итог был тихий: SUMMARY
советовал `PATH` на несуществующий каталог, а `_pq_openssl_bin` в
`menu_telemt.sh` искал `/opt/openssl-3.5/bin/openssl` — и PQ-часть пункта 5
оставалась «Пропущено» даже после успешной пересборки. Добавлен
`make install_sw` с проверкой запуском бинарника. Порядок важен: установка
обязана пройти **до** этапа 2, потому что nginx с `--with-openssl=<исходники>`
делает в том же дереве `make clean` и пересобирает OpenSSL под себя.

**C14 закрыт.** `systemctl stop nginx` по инварианту 2 уносил `telemt` и
`telemt-panel`, а поднимался только nginx: после 20–40 минут печаталось
зелёное «Готово» над мёртвым прокси. Теперь список активных служб снимается
**до** остановки, поднимается в обеих ветках (успех и откат), проверяется
фактом через `wait_until`, а итоговая рамка при неподнявшейся службе краснеет
и скрипт возвращает 1. Пункт 9 меню читает этот код и печатает фактическое
состояние трёх служб.

**Откат стал полным.** Бэкапился бинарник и `modules-enabled`, но не
`nginx.conf`, из которого скрипт удаляет строку `load_module
ngx_stream_module.so` — прежнему, динамическому, бинарнику она необходима.
Откат оставлял сервер без `stream`, то есть без разбора SNI на 443. Добавлен
`nginx.conf.pre-openssl35.bak`.

**`DRY_RUN=1`** печатает решения отбора и итоговые флаги `./configure`, ничего
не меняя. Операция необратимая и на 20–40 минут — её решения стоит увидеть
заранее.

### Чего проверка не покрыла

Логика отбора модулей прогнана на заглушках (8 групп проверок, включая
однострочные `location { image_filter ... }` и отсутствие `stream`), сухой
прогон — на подставном `nginx -V`/`-T` с флагами Ubuntu 24.04. **Настоящая
сборка на живом сервере не запускалась.** Пока она не прошла, дефект считать
закрытым нельзя.

### Известная дыра рядом, не чинилась

Флаги `--add-dynamic-module=<путь>` фильтр не трогает и не трогал: они не
содержат `=dynamic` и проходят мимо ветки конвертации. Модуль соберётся в
`objs/`, но устанавливается только бинарник, а `modules-enabled` вычищается —
значит сторонний динамический модуль (brotli, geoip2) после пересборки
исчезает молча. На стенде таких модулей нет.

### Артефакт MTProxyL «Установить PQ OpenSSL (из Release)» — не подходит

Проверено по их `.github/workflows/build-pq-nginx.yml`: **в сборке нет модуля
`stream`**, только http-модули. Подстановка их бинарника убьёт маршрутизацию 443
целиком. Плюс у них зашит `--prefix=/opt/mtproxyl-nginx`, и их nginx — отдельная
служба, а не замена системной: PQ достался бы их стеку, не нашему.

Заимствовать стоит не функцию, а идею: собирать **свой** артефакт в GitHub
Actions с нашим набором модулей. Снимет и 20–40 минут компиляции, и `apt-mark
hold`, который сейчас останавливает security-обновления nginx. Workflow-ов в
репозитории пока нет.

## 4. Что проверено на живом сервере

Около 90 проверок, 0 итоговых провалов — но не с первого раза.

**Миграция на существующей установке:** переезд панели полный (loopback, `[tls]`
снят, порт закрыт, ACL отозван, правило ufw убрано, адрес отвечает 200); целость
стека сохранена (отпечатки и ALPN на порту маски и 443 совпадают, сквозной
self-SNI даёт 200); учётки с паролем из `\`, пробела и `$` возвращаются байт в
байт; восстановление служб после падения nginx работает.

**Установка с нуля на свежей Ubuntu** при работающем `unattended-upgrades` —
прошла, `wait_for_apt` отработал. Стек 18/18. Панель сразу встала по новой схеме.

**Боты:** объединённый режим 13/13; режимы «только telemt-bot» и «только
3xui-bot» — **проверены впервые**, 14/14, взаимоисключение работает, данные
переживают смену режима.

**UFW:** правила добавляются до включения, новое ssh-соединение после включения
устанавливается, порты стека доступны, выключение без потери связи.

**Прочее:** BBR, часовой пояс, IPv6, главное меню (2 с на отрисовку), GeoIP
(источник живой, City 63 МБ), скрипт карты (7 функциональных тестов).

### Что НЕ проверено

- Режим ботов «два отдельных бота» — нужен второй токен Telegram.
- Разрушающие пункты: удаление стека, удаление панели, удаление ботов.
- Меню тестов (censorcheck, YABS, iPerf3, sysbench, сканеры), утилиты, WARP.
- Пункты X-UI: патч, AdGuard, бэкап и восстановление.
- MTProxyL — установка и режим Reanimator.
- SSL-меню: выпуск сертификата и реальный Ctrl+C для проверки `trap`

## 5. Грабли — прочитать до начала работы

### Класс дефектов, встреченный чаще всего

**Рапорт об успехе поверх сломанной системы.** За сессию поймано шесть таких, из
них два — в коде, написанном в этой же сессии:

- пункт «Восстановить конфиги» печатал «✅ Панель доступна» при 404, потому что
  проверял код возврата применения конфига, а не фактический ответ;
- проверка панели спрашивала раньше, чем панель поднималась (`systemd` возвращает
  управление сразу после форка);
- `update_geoip.sh` всегда возвращал 0 — последней командой стоял `echo`;
- `wait_for_apt` печатал «продолжаю» и возвращал 1, обрывая установщик;
- «всегда включать IPv6» оставляло отключённым `::1`;
- скрипт бэкапа 3x-ui превращался в пустышку при обрыве загрузки.

Вывод, который стоит держать в голове: **проверять результат фактом, а не кодом
возврата предыдущего шага**.

### Что уже пробовали — не повторять

| Попытка | Почему не сработала |
|---|---|
| `tr -d '\0'` для очистки вывода `openssl s_client` | Ломает разбор: перестают находиться `Protocol` и `Cipher`. Решение — временный файл |
| Захват вывода `s_client` в переменную | Нулевые байты, bash предупреждает и портит поля |
| Артефакт PQ nginx от MTProxyL | Нет модуля `stream` |
| Теория «маска отличима по шифрам» | Измерением не подтвердилась: vhost панели задаёт те же значения, что были захардкожены. Зеркалирование всё равно полезно как устойчивость, но живой дырой это не было |
| `pkill -f "<шаблон>"` при работе с меню через pty | Убивает собственную ssh-сессию, если шаблон совпадает |
| Обрезание лога живой сессии `script` | `script` держит offset, файл читается как нули |
| `[[ условие ]] && присваивание` под `set -e` | Ложное условие возвращает 1 и роняет скрипт. В проекте принята полная форма `if/fi` |
| `CODE="$(curl ...)"` под `set -e` | Падает раньше строки с `die`, причина не видна. Нужен `|| true` |

### Особенности окружения разработки

- **Windows + git-bash:** `chmod` и `umask` — no-op, `stat` всегда показывает
  644. Права проверяются только на Linux.
- **`python`/`python3` на Windows** могут быть заглушками Microsoft Store —
  печатают «Python» и выходят с ненулевым кодом. Python-код проверять на сервере.
- **Прогон интерактивных меню без TTY:**
  ```bash
  printf '4\n\nX\n' | timeout 180 bash menu_telemt.sh 2>&1 | sed 's/\x1b\[[0-9;?]*[a-zA-Z]//g'
  ```
  `timeout` обязателен: при EOF цикл меню крутится вечно.
- **Длинные операции** запускать через `nohup setsid ... > /tmp/x.log 2>&1 &` и
  опрашивать лог.

## 7. Соглашения проекта

**Комментарии объясняют «почему», а не «что»** — как правило, описывают дефект,
который уже случался. Это не украшение, а способ не наступить второй раз.

**Коммиты** — Conventional Commits, тема и тело на русском, тело объясняет
причину и последствия. В конце строка `Co-Authored-By: Claude Opus 5
<noreply@anthropic.com>`.

**Разрушающие операции** подтверждаются вводом слова целиком (`СТЕРЕТЬ`,
`УДАЛИТЬ`), регистр учитывается. При добавлении пунктов меню разрушающий сдвигать
только **от** привычной позиции, никогда к ней.

**Рабочий цикл:** правка → код-ревью → коммит → пуш в `main`. На сервере
обновление — `git -C /root/VSM pull origin main`; при добавлении новых файлов
ещё и `bash /root/VSM/install.sh` для пересоздания симлинков.

> **Важно:** новый файл модуля обязан попасть в git с битом исполнения
> (`git update-index --chmod=+x`). `install.sh` делает `chmod +x`, и файл,
> закоммиченный как `100644`, ломает `git pull` у всех, кто уже поставил VSM.

- секрет MTProto передаётся в `argv` установщику telemt и виден в `ps`;
- удаление панели на QEMU-процессоре не выполняется: `check_cpu` патчится только

## 9. С чего начать

```bash
git clone https://github.com/adkudryashov/VSM.git && cd VSM
git log --format='%h %s' -25          # работа последней сессии
cat docs/CODEMAPS/architecture.md     # устройство и инварианты
```

Первая задача — прогнать починенную пересборку на живом сервере. Код готов и
проверен на заглушках, но настоящей сборкой не подтверждён (раздел 3):

```bash
DRY_RUN=1 bash rebuild-nginx-openssl35.sh   # решения отбора, система не тронута
nohup setsid bash rebuild-nginx-openssl35.sh > /tmp/rebuild.log 2>&1 &
```

Итог принимать только по фактам: `nginx -V` показывает OpenSSL 3.5.6,
`/opt/openssl-3.5/bin/openssl version` запускается, пять служб `active`,
отпечатки на порту маски и 443 совпадают со слепком, а пункт 5 «Сверить TLS
маски и панели» даёт PQ на **обоих** портах.

Перед любыми изменениями на сервере снять слепок:

```bash
ss -ltn > /root/ports-before.txt
systemctl is-active nginx x-ui telemt telemt-panel
```

И держать в голове главный критерий целости — **совпадение отпечатка
сертификата и ALPN между портом маски и портом 443**. Проверяется пунктом
«Сверить TLS маски и панели» или вручную:

```bash
D=<домен панели>
for p in <порт маски> 443; do
  echo | openssl s_client -connect 127.0.0.1:$p -servername $D 2>/dev/null \
    | openssl x509 -noout -fingerprint -sha256
done
```

Отпечатки обязаны совпасть побайтно.
