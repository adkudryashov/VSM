# Пункты меню VSM

Справочник по всем разделам. Нумерация совпадает с экраном. Короткое
введение и установка — в [README](../README.md).

## Главное меню

| № | Раздел | Что внутри |
|---|---|---|
| 0 | Доступы и домены | Адреса панелей, логины и пароли, домены. Пароли скрыты до нажатия `P` |
| 1 | Панель X-UI | Установка и обслуживание 3x-ui |
| 2 | Стек telemt | Прокси для Telegram, веб-панель, MTProxyL, обновление |
| 3 | Telegram-боты | Бот-монитор, сторож, сводка за сутки |
| 4 | Тестирование | Доступность из России, скорость, качество IP, сканеры |
| 5 | Настройка системы | BBR, ICMP, фаервол, IPv6, сертификаты, часовой пояс, WARP, защита |
| 6 | Системные утилиты | Ресурсы, диск, трафик, порты, пинг, очистка, beszel |
| 7 | Обновить VSM | Скачать новую версию и перезапустить ботов, без перезагрузки |

## 1 — Панель X-UI

| № | Пункт | Что делает |
|---|---|---|
| 1 | Установить | Панель, nginx, сертификаты, подписка Clash. **Стирает существующую панель**, требует слово `СТЕРЕТЬ` |
| 2 | Применить патч | Переписывает настройки nginx от автора 3x-ui-pro, базу не трогает. Саму 3x-ui не обновляет. После него — «Восстановить nginx» в стеке |
| 3 | Учётные данные | Запомнить логин и пароль или сменить пароль прямо в панели |
| 4 | Бэкап | Полный архив скриптом автора (панель на время останавливается) и лёгкий снимок из суточной копии VSM |
| 5 | Управление службой | Статус, запуск, остановка, перезапуск |
| 6 | Открыть панель | Штатное меню `x-ui`, в том числе обновление 3x-ui |
| 7 | AdGuard Home | DNS с блокировкой рекламы на домене панели |
| 8 | Роутер (XKeen) | Подписка mihomo и кнопка **XKeen** на странице подписки клиента: все подключения одной ссылкой, роутер обновляет её сам |
| 9 | Шаблон настроек | Снять с сервера оформление панели (подписки, названия, параметры) и наложить на свежую панель другого сервера. Секретов и клиентов в шаблоне нет |
| 10 | Удалить X-UI Pro | Требует `УДАЛИТЬ`. Сносит панель вместе с настройками nginx, а значит и прокси стека. Сертификаты остаются |

**Перенос оформления на новый сервер.** На старом: пункт 9 → «Снять с этого
сервера», затем «Перенести» — меню покажет команду копирования. На новом
сервере установка стека или пункт 1 сама найдёт шаблон и спросит название
сервиса. До наложения снимается копия базы, после — проверка, при сбое
откат. Клиентов заводят заново: у нового сервера другие ключи.

## 2 — Стек telemt

| № | Пункт | Что делает |
|---|---|---|
| 1 | Установить весь стек | 3x-ui-pro, telemt, веб-панель, WEB Proxy. **Стирает существующую панель**, требует `СТЕРЕТЬ` |
| 2 | Добавить telemt | К уже работающей 3x-ui-pro, её базу не трогает |
| 3 | Веб-панель | Поставить telemt_panel, сменить секретный путь, снять |
| 4 | Диагностика | Службы, настройки, сквозная проверка. Внизу — расхождения, которые можно принять как норму |
| 5 | Восстановить nginx | Вернуть настройки VSM после патча 3x-ui-pro |
| 6 | Сверить TLS | Проверить настройки шифрования |
| 7 | Учётные данные | Адреса, логины и пароли стека |
| 8 | Управление службами | Запуск, остановка, журналы |
| 9 | MTProxyL | [Доработки для telemt](https://github.com/Liafanx/MTProxyL). Нужен режим **Reanimator** |
| 10 | Пересборка nginx | Новая версия OpenSSL, 20–40 минут, требует `СОБРАТЬ`. После неё обновления nginx ставятся только повторной пересборкой |
| 11 | WEB Proxy | Включить или вернуть, ссылки для пользователей |
| 12 | Обновить telemt | До последней или выбранной версии: пробный запуск на вашем конфиге, при сбое откат |
| 13 | Удалить стек telemt | Убирает telemt и панель; 3x-ui и сертификаты остаются. Требует `УДАЛИТЬ` |

## 3 — Telegram-боты

| № | Пункт | Для чего |
|---|---|---|
| 1 | Объединённый бот | Всё в одном чате. Рекомендуется |
| 2 | Два отдельных бота | Два токена, две службы |
| 3 | Только telemt | Только прокси |
| 4 | Только 3x-ui | Только панели |
| 5 | Обновить код | С GitHub; при своих правках в `bots/` спросит `СТЕРЕТЬ` |
| 6 | Сторож | Тревоги, проверка из России, подключение хаба beszel |
| 7 | Настройки | Текущие настройки ботов |
| 8 | Управление | Запуск, остановка, журналы |
| 9 | Удалить ботов | Требует `УДАЛИТЬ`; история и базы в `bots/data` сохраняются |

**Что умеет бот.** Состояние прокси и панелей 3x-ui, история подключений,
карта подключений, тревоги сторожа (прокси упал, пропала связь с серверами
Telegram, сбились часы, прокси недоступен из России), напоминание о сроке
аренды VPS.

**Сводка за сутки** — каждый день в 22:00 по Москве: трафик по клиентам,
попытки подбора пароля и баны, сбои за день, проверки из России, суточная
копия, что нужно обслужить. Кнопка под сводкой выключает и включает рассылку;
кнопка «📅 За сутки» и команда `/digest` — сводка в любой момент. Время и пояс
меняются в `bots/.env` (`DIGEST_TIME`, `DIGEST_TZ`).

**Карта подключений** содержит адреса всех пользователей с городом и
провайдером, поэтому открывается только по случайной ссылке.

**Все серверы одним экраном** — кнопка «🖥 Серверы», если подключён хаб
[beszel](https://beszel.dev). В хаб указывайте ту учётную запись, под которой
заводились серверы: в beszel сервер видит только тот, кто его добавил.

## 4–6 — Остальные разделы

| Раздел | Пункты |
|---|---|
| 4 Тестирование | Регион IP · доступность из России · iPerf3 · YABS · IPQuality · параметры сервера · sysbench · RealiTLScanner · DPI Detector · SNI Scan |
| 5 Настройка системы | BBR · ICMP · фаервол UFW · IPv6 · сертификаты · часовой пояс · Cloudflare WARP · **8** бан подбора SSH · **9** автообновления |
| 6 Системные утилиты | Ресурсы · место на диске · трафик · порты · внешний адрес · пинг и маршрут · проверка домена · очистка · **9** beszel (агент и хаб) · завершить процесс |

Тесты скорости на слабом сервере идут долго, до десятков минут.

Фаервол при включении сначала разрешает текущий порт SSH, иначе вход на
сервер закрылся бы.

Сертификаты продлеваются сами, без остановки сайта. Проверить продление, не
дожидаясь срока: **5** → сертификаты → «Проверить автопродление».

## Опасные операции

Всё, что нельзя откатить, подтверждается вводом слова целиком, а не `y`.

| Операция | Слово | Что сохранится |
|---|---|---|
| Установка стека или панели с нуля | `СТЕРЕТЬ` | Ничего: панель ставится заново |
| Удалить X-UI Pro | `УДАЛИТЬ` | Сертификаты. Прокси стека **не** сохранится |
| Удалить стек telemt | `УДАЛИТЬ` | 3x-ui, сертификаты; конфиг — по отдельному вопросу |
| Сменить веб-панель на другую | `ДА` | Ничего от прежней панели, копия снимается |
| Удалить ботов | `УДАЛИТЬ` | История подключений, список панелей |
| Обновить код ботов при своих правках | `СТЕРЕТЬ` | Спрашивается, только если правки есть |
| Пересборка nginx | `СОБРАТЬ` | Прежняя версия, откат при сбое |
| Замена telemt | `ОБНОВИТЬ` / `ОТКАТ` | Прежняя версия |
| Удалить хаб beszel | `УДАЛИТЬ` | Копия данных хаба |

## Что VSM хранит на сервере

Всё с секретами создаётся с правами `600` (каталоги — `700`) и принадлежит
root.

| Путь | Что внутри |
|---|---|
| `/root/VSM` | Сам VSM; в `/usr/local/bin` — одна команда `vsm` |
| `/etc/vsm/` | Домены, логины и пароли панелей, секрет прокси, режим ботов |
| `/root/VSM/bots/.env` | Токен бота и Telegram ID администраторов |
| `/root/VSM/bots/data/` | История подключений, список панелей с токенами, состояние сторожа и сводки |
| `/var/backups/vsm/` | Суточная копия настроек и снимок панели, прежние версии telemt |

Пароль панели 3x-ui VSM прочитать не может: панель хранит его в виде хэша.
Пункт «Учётные данные» либо запоминает пароль, который вы знаете, либо меняет
его в панели и запоминает новый.
